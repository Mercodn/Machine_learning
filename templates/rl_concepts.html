🤖 Reinforcement Learning - Basic Concepts

Learn how agents learn from reward and punishment by interacting with an environment.

What is Reinforcement Learning?

Reinforcement Learning (RL) is a type of machine learning where an agent learns to make decisions through trial and error. The agent takes actions in an environment, receives rewards or punishments, and updates its behavior to maximize cumulative reward.

Key Concepts

  • Agent: The decision-maker that chooses actions.
  • Environment: The world where the agent acts and receives feedback.
  • Action: A choice made by the agent, such as selecting arm 1, arm 2, or arm 3.
  • Reward: A numerical signal received after each action. Positive reward encourages the action, while negative reward punishes it.
  • Policy: The strategy the agent uses to choose actions.
  • Exploration vs. Exploitation: The agent must balance trying new actions to learn (exploration) and choosing known good actions to get reward (exploitation).

Reward and Punishment

In RL, the agent receives a reward signal after each action. Reward can be positive, indicating a good result, or negative, indicating a penalty. The agent adjusts its action values over time to prefer actions with higher expected reward.

Example formula for action-value update:

new_value = old_value + (reward - old_value) / count

This formula updates the expected reward for the chosen action after each step.

Why RL is different from Supervised Learning

Supervised learning uses labeled examples where the correct answer is known. Reinforcement learning instead learns by interacting with the environment and receiving feedback. It is ideal for sequential decision-making and problems with trial-and-error learning.

Real-World Applications

Game Playing

Training agents to play chess, Go, or video games.

Robotics

Teaching robots to move, balance, and interact safely.

Recommendation Systems

Optimizing content recommendations based on user interactions.

Resource Management

Allocating resources dynamically in networks and logistics.
